Como primeira tarefa, criamos o StudyFlow.
O StudyFlow é uma aplicação web para ajudar estudantes a organizar seus objetivos de estudo. A aplicação permite cadastrar, visualizar, editar e excluir objetivos, além de armazenar as informações localmente para que os dados sejam preservados após a atualização da página.
